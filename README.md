Nome do projeto: AutoGestão
O projeto AutoGestão é um sistema informatizado de gerenciamento para pequenas oficinas mecânicas, 
criado para organizar o cadastro de clientes e veículos, o registro dos problemas relatados e a elaboração de orçamentos. 
Seu objetivo é substituir registros manuais, como cadernos e planilhas, e reestruturar a rotina diária da oficina.
Foram observadas diversas necessidades relacionadas à forma como os registros são feitos, em sua maioria anotações escritas em cadernos ou planilhas que exigem alteração manual. 
Nota-se que esse processo é demorado e toma muito tempo de quem faz o registro, além de aumentar as chances de perda ou corrupção das informações. 
Sendo assim, o sistema pretende otimizar o processo de registro, garantir maior segurança no armazenamento dos dados e facilitar a consulta de clientes e veículos, 
inclusive em situações de urgência.

Principais funcionalidades:
•	Cadastro de clientes (Nome, telefone, endereço);
•	Cadastro de veículos (Marca, modelo, ano, placa);
•	Registro dos mecânicos envolvidos com a manutenção;
•	Registrar problemas relatados e abrir ordens de serviço;
•	Gerar, aprovar ou reprovar orçamentos;
•	Consultar histórico de serviços de um veículo;
•	Controlar estoque de peças;
